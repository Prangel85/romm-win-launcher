# RomM Win Launcher

Minimal launcher for Windows that connects to a RomM server.

## Planned features (minimal first)

- Authenticate with Client API Token
- List ROMs from RomM
- Download selected ROMs
- Launch games with the correct RetroArch core
- Auto-sync saves/states on game exit and on app start

## Requirements

- Python 3.10+
- RetroArch installed
- RomM server with Client API Token

## Usage

```bash
pip install -r requirements.txt
python main.py
```
